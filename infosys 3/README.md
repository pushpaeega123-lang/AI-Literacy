# 🤖 AI Literacy Support Assistant

## 📖 Project Description

The AI Literacy Support Assistant is a web-based learning platform developed using Flask and SQLite. It helps learners improve their literacy skills through AI-based recommendations, lessons, quizzes, and progress tracking.

---

## 🚀 Features

- User Registration
- User Login
- Secure Authentication
- Language Selection
- Personalized Dashboard
- AI Learning Recommendations
- Lesson Management
- Assessment Module
- Progress Tracking
- Responsive Design
- Modern UI with Bootstrap
- Hover Effects and Animations

---

## 🛠 Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
